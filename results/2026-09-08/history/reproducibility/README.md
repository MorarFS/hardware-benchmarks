# Historical execution snapshot

These scripts and configurations preserve the original experiment, including its adaptive retries and API failures. Private root paths and host identifiers were replaced with placeholders. They are archival evidence, not turnkey cross-platform launchers. The original snapshot manifest retains original hashes; `../public-file-manifest.json` hashes the sanitized published files.

The portable history helpers live under `scripts/history/`. Their command help and syntax were checked; the adapted wrapper was not used to regenerate this historical dataset. Use the separately documented history-v2 runner for the frozen follow-up pilot.

The canonical public-domain extraction is `../source/pages.json`. Physical PDF pages and source text hashes preserve the original input. Re-extraction with another PDF/OCR library may produce different text and must be labeled separately.
