# History-v2 on Intel Arc Pro B70

This is an Arc SYCL configuration variant of the frozen Evo source-fidelity pilot. It reuses the exact source passages, questions, prompts, output budgets, stage ordering, and 17-file integrity manifest from repository commit `12cca05a88b731eda809bbec06e5d6e583ca000e`. Windows checkout newline conversion was corrected by restoring frozen Git blob bytes; all 17 hashes validate. The original fixtures were not revised.

The three previously downloaded models are Qwen3.6 35B-A3B UD-Q4_K_M, Gemma 4 26B-A4B Instruct bartowski Q4_K_M, and Qwen3.8 27B UD-Q4_K_M. Exact hashes are verified again before loading. These are not the exact Evo profiles: Gemma uses a different quantizer, Qwen35 lacks the bundled MTP component, and Qwen27 replaces no named Evo model. GPT-OSS 120B is not run.

The runtime is llama.cpp b10852 SYCL on the external Intel Arc Pro B70. Requested settings are full GPU layer offload, one slot, 65,536 context tokens, F16 K/V cache, flash attention, 512 batch/microbatch, ten CPU threads, seed 42, reasoning off, and no speculative decoding. Sampling matches the frozen reasoning-off profiles: temperature 0, top-p 1, top-k 40, min-p 0, repeat penalty 1. Logs and model properties provide load evidence. Configuration failures must remain failures rather than silently reducing context or changing cache types.

Each model receives twelve independent requests: two development probes, extraction and direct summary for each of four passages, a synthesis of four generated summaries, and a control using all four original passages. The generation runner hashes gold files for integrity but never parses or sends gold answers. Questions and extracted answers do not enter summary requests. Capped, empty, or failed direct summaries block merged synthesis. Requests have a 900-second deadline and no automatic retry; timeout or transport failure stops that model and shuts down its server.

This adapter uses llama-server's OpenAI-compatible streaming interface rather than LM Studio's native API. Raw streams, exact requests, outputs, server usage/timings, first-visible delay and wall time are retained. Token denominators must not be pooled with Evo SDK/native rates. This is not a synthetic tokens-per-second run, and server loading is excluded from request timing.

Judgments compare outputs against the supplied Oman passages. They are Codex/AI-assisted source checks, not independent human adjudication or certification of modern historical truth. Extraction uses separate categories and citation judgments, with a separate denominator for the four source-absent questions. Summary/synthesis factual errors, coverage omissions and formatting constraints are distinguished. Generation completion alone is not an accuracy score.
